# 🔮 Jesse AI — Autonomous Desktop Jarvis Assistant

Полноценное настольное приложение нового поколения для ПК на базе **Electron + React + TypeScript + Python**, интегрированное с защищенной базой данных **Supabase PostgreSQL** и оснащенное нейросетевым голосовым управлением.

---

## ⚡ Ключевые возможности

1. **Голосовой диалог и нейронный голос (Edge-TTS)**:
   - Бесплатный синтез речи нейросетью с реалистичными голосами (`ru-RU-DmitryNeural`, `ru-RU-SvetlanaNeural`).
   - Голосовой ввод команд через Web Speech API в один клик.

2. **Полное управление ПК (Jarvis Protocol)**:
   - **Громкость**: изменение, установка точного процента («поставь звук на 45%»), включение/выключение звука.
   - **Яркость**: регулировка яркости монитора («яркость 80%», «сделай ярче»).
   - **Запуск программ**: мгновенный запуск Telegram, Discord, Steam, Spotify, Калькулятора, Блокнота, Диспетчера задач, Браузера и др.
   - **Медиа**: переключение треков, пауза/воспроизведение.
   - **Мониторинг железа**: отображение нагрузки процессора (ЦП), оперативной памяти (ОЗУ), диска и батареи в реальном времени.
   - **Безопасность**: мгновенная блокировка ПК по команде («заблокируй компьютер»).

3. **Защищенная система лицензирования (Supabase PostgreSQL)**:
   - Проверка ключа доступа на валидность и срок годности с защитой от SQL-инъекций (параметризованные запросы).
   - Поддержка различных тарифных планов и отображение оставшихся дней.
   - Сохранение профиля: возможность изменить имя пользователя и настройки голоса.
   - Полная история чатов в облаке с возможностью переключения и удаления.

4. **Интерфейс & Дизайн**:
   - Фирменная **черно-фиолетовая тема** с неоновыми акцентами и эффектом глубокого матового стекла (*Glassmorphism*).
   - Слева сверху: Название **Jesse AI** и кастомизируемый подзаголовок.
   - Справа снизу: Главная кнопка **«ЗАПУСК»** и всплывающий пульт быстрого управления параметрами ПК.
   - Слева снизу: Кнопка **Profile** для открытия окна подписки и настроек.

## 🚀 Запуск приложения

### Способ 1: Двойной клик по файлу
Запустите файл [start.bat](file:///c:/Users/stuck/Desktop/ai/start.bat) в папке проекта.

### Способ 2: Через терминал
```bash
npm run dev
```
Команда автоматически запустит:

2. Vite dev-сервер на порту `5173`
